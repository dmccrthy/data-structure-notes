### Memory Fragmentation
    - Occurs when the used memory of a process differs from what is allocated to it.
    - Internal Fragmentation
        - Occurs when more space is allocated to a process than what is actually used.
        - The space that is reserved but not used is referred to as an internal fragment.

    - External Fragmentation
        - D

### Space Overhead
    - Generally this is the extra space used by a data structure beyond its actual data.
    - An example would be an array, which has 4 bytes of overhead due to 4-bytes being used to store the memory address of the first index.
