## Sorting Algorithms

**Comparison vs Non-Comparison**

As the name would imply, Comparison sorting algorithms sort by comparing the values of an array, while Non-comparison do not. Broadly speaking sorting algorithms can be broken done into these two groups.

## Comparison Based

### Bubble Sort

| Time: | Space: |
|:-----:|:------:|
|  O(n^2)  |  O(1) (inplace)   |

    - Simplest sorting algorithm, which moves through each element in the array, and compares it to all other elements.
    - This is pretty much the brute force way of sorting.

### Merge Sort

| Time: | Space: |
|:-----:|:------:|
|  O()  |  O()   |

    - Works by breaking down an array into individual elements, and then rebuilding the array in sorted order.

## Traversals

### Depth First Search

    - fd


Inorder
Traverse nodes in a (Left -> Root -> Right) pattern recursively.
Time Complexity: O(n) 
Preorder
Traverse nodes in a (Root -> Left -> Right) pattern recursively.
This differs from Level Order traversals as it takes the root value then continues down to the bottom of the subtree.
Time Complexity: O(n) 
Postorder
Traverse nodes in a (Left -> Right -> Root) pattern recursively.
Time Complexity: O(n) 

### Breadth First Search

    - fff


Level Order
Traverse nodes in a (Root -> Left -> Right) pattern recursively.
This creates the BFS effect
Time Complexity: O(n)
